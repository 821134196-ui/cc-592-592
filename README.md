# 超市散装食品称重标签错贴纠正系统

散装食品称重标签一旦贴错（商品错、重量错），在付款前和结账后分别走不同的纠正流程，
保证**价格与过敏原信息始终有据可查**。

- 后端：Python · FastAPI · SQLAlchemy · SQLite
- 前端：Vue 3（本地 vendor 单文件，**无需 npm、无需联网、无需构建**）
- 本地模拟设备：称重标签打印机、收银扫码枪、小票打印机（均为 HTTP 接口）
- **一条命令启动**：`./run.sh`

## 快速开始

```bash
./run.sh            # 自动建 venv、装依赖、建库灌种子、启动 → http://127.0.0.1:8000
./run.sh demo       # 命令行演示三大业务场景（独立演示库，不污染正式数据）
./run.sh reset      # 删除 data/scale.db 后重新开始
```

页面右上角切换操作人员（无需密码）：

| 账号 | 角色 | 权限 |
|---|---|---|
| `cashier01` 收银员小王 | cashier | 称重、注销标签、收银结账、**只能发起**纠错申请 |
| `mgr01` 主管李姐 | supervisor | 调价、审批/驳回纠错、差额补收退款 |

## 业务规则如何落地

### 1. 唯一条码标签
称重台每次称重生成全局唯一条码（`29` 开头 13 位），标签与数据库记录一一对应，
清楚显示**商品、净重、批次、单价、金额、过敏原**；过敏原在打印瞬间写入快照，
之后商品档案修改也不改变已打印标签。

### 2. 付款前贴错 → 重新称重、注销旧码、扫码必拦
- 称重台对有效标签执行「重新称重补打」：生成新码，旧码置为 `voided` 并记录注销原因与操作人。
- 收银扫码时，作废码 / 重复使用码 / 不存在码一律返回 `409`，**前端红色强制拦截，不得入账**。
- 付款前还可整行移除扫描，标签恢复有效。

### 3. 交易保存成交价，事后调价不影响原订单
- 交易行保存成交瞬间的单价、净重、金额（`TransactionItem` 快照）。
- 调价写入 `price_changes` 留痕；原订单查询、小票补打永远打印成交价，现价仅作参考列展示。
- 新称的标签按新价计价。

### 4. 已结账订单不能换货 → 主管核对差额
- 已结账订单不能直接换商品/改重量：收银员在订单明细里**只能发起纠错申请**（pending）。
- 主管核对原标签与实物：选择实物商品与实物净重后「与原交易核对试算」。
- 差额按**原订单成交时点**的单价计算（依据调价历史回溯），避免调价干扰纠错。
  - 实物应收 > 原收 → **补收**；< 原收 → **退款**；= 原收 → 无差额。
  - 收退方向与核对结果冲突时（如该退款却选补收）后端直接拒绝。
- 核准后原交易金额**原样保留**，纠错单记录实物信息、差额、原因、主管与备注；申请也可驳回。

### 5. 过敏原 / 批次追溯
「订单 / 过敏原追溯」页按批次（可加过敏原名称过滤）查出：
同批次**已售出可能受影响的订单**（订单号、状态、条码、金额、过敏原）以及未售出/已注销标签。

## 演示的三个场景（`./run.sh demo`）

1. **作废标签重扫**：错称 0.80kg → 补打 0.75kg 新码、旧码作废 → 扫旧码返回
   `409 标签已作废…扫码拦截，禁止入账` → 新码正常入账结账。
2. **调价后原价查询**：曲奇 56 元/kg 成交后主管调为 62 元 → 原订单与补打小票仍为
   56.00 / 28.00 元 → 新标签按 62 元计价。
3. **结账后差额处理**：两笔花生糖订单实物分别是果冻（退款 13.45）和虾片（补收 11.61）；
   收银员自行审批被 403 拒绝；主管试算核对，收退方向冲突被拦截；核准后原金额不变，
   差额独立留痕；并按批次 B20261003-07 追溯含花生的全部订单。

## 目录结构

```
backend/app/
  database.py   # SQLite 引擎/会话
  models.py     # 商品/批次/过敏原/称重标签/交易/调价/纠错 ORM
  schemas.py    # Pydantic 模型
  services.py   # 核心业务（作废拦截、价格快照、差额核对、批次追溯）
  main.py       # FastAPI 路由 + 模拟设备接口 + 静态托管
backend/seed.py # 演示种子
scripts/demo.py # 三大场景端到端脚本（TestClient）
static/         # index.html / app.js / styles.css / vendor/vue.global.prod.js
run.sh          # 一条命令启动
```

## 主要 API

| 方法 路径 | 说明 |
|---|---|
| `POST /api/device/print-label` | 模拟标签打印机（称重+出标签） |
| `GET  /api/labels/{barcode}/paper` | 按唯一条码补打标签样张 |
| `POST /api/labels/void` | 付款前注销标签 |
| `POST /api/txn/scan` | 收银扫码（作废/重复/无效码 409 拦截） |
| `POST /api/txn/pay` | 结账（金额冻结） |
| `GET  /api/txn/{no}/receipt` | 模拟小票打印机（成交价） |
| `POST /api/products/price-change` | 调价留痕 |
| `GET  /api/txn/{no}` | 订单查询（成交单价 + 现价参考） |
| `POST /api/corrections` | 收银员发起纠错申请 |
| `POST /api/corrections/preview` | 主管按原成交时点价格核对差额（试算） |
| `POST /api/corrections/review` / `reject` | 主管核准补收/退款或驳回 |
| `GET  /api/trace/batch/{batch_no}` | 过敏原批次追溯 |

> 说明：本系统为单机演示，角色切换用于展示权限边界（收银员无法审批纠错、无法越权），
> 未做真实登录认证；条码为内部称重码（29 前缀），不使用商品国标码。
